# Introducing NEXUS 0.6.13

**Your agents, projects and tools. One Windows workspace.**

NEXUS 0.6.13 brings a redesigned Home, Chat Studio, Store and Settings together with clearer API and MCP management.

- Coordinate specialist work with NEXUS Manager and 300 editable roles.
- Choose connected agents and models, attach project context, and inspect workflow, activity and file changes.
- Explore skills, MCP connections and supported local models in the Store.
- Configure 16 chat provider presets and explore 138 researched API services with setup checklists and official references.
- Personalize your workspace in English or Arabic, with light and dark themes.

[Download the Windows installer or portable EXE](https://github.com/Ahmed-Khalil-Mohamed/NEXUS/releases/tag/v0.6.13) · [Screenshots and guide](https://github.com/Ahmed-Khalil-Mohamed/NEXUS)

API research is guidance, not automatic service activation. Providers may require their own accounts, credentials and billing. The 300 roles run through chosen providers; they are not bundled models.
