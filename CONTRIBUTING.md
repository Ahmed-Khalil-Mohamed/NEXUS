# Contribute to NEXUS

NEXUS is proprietary software with a public distribution and documentation repository. You can help by reporting issues, suggesting improvements, correcting docs, and sharing your experience.

## Report a bug

Use the [bug report form](https://github.com/Ahmed-Khalil-Mohamed/NEXUS/issues/new/choose). Include the version, Windows version, selected provider, exact reproduction steps, and expected versus actual behavior. Crop or redact screenshots before sharing. Do not attach account credentials, private project files, full logs, or the workspace database.

## Suggest a feature or ask a question

Use the feature request form for a concrete workflow improvement. Include the problem and an example of the desired outcome. Use [Discussions](https://github.com/Ahmed-Khalil-Mohamed/NEXUS/discussions) for usage questions and launch feedback.

## Documentation changes

Small, focused pull requests to this public repository are welcome for documentation corrections. Keep public copy and campaign artwork in English. Describe what changed and check local Markdown/image links. Application source changes belong in the private repository and require authorization from its owner.

## Share the launch

Use the [launch kit](docs/LAUNCH-KIT.md) and official Releases URL. Identify the current version as a public preview. Do not claim guaranteed results, bundled AI subscriptions, 300 simultaneous models, or provider endorsement. Avoid unsolicited bulk promotion.

Public contributions do not change the proprietary license of NEXUS application code.
