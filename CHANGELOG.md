# Changelog

## 0.6.13 — 2026-10-16

Consolidates 0.6.7–0.6.13: Advanced API research, workspace intelligence and usage, redesigned Home and model comparison, Chat Studio and Mix, Store, Settings and connection management. Includes all 138 API profiles and 16 chat presets. [Release notes](docs/RELEASE-0.6.13.md).

## 0.6.6 — A new home for your AI workflow

Released 2026-10-14. [Full release notes](docs/RELEASE-0.6.6.md).

- Rebuilt Home with a draft composer, connection selection, recent conversations and workspace shortcuts.
- Added one-to-three-model comparison cards, shared usage estimates and a searchable pricing directory.
- Reorganized official AI announcements with publisher images and explicit fallback states.
- Introduced neutral/petroleum light and dark palettes, refined chat controls and reduced-motion support.
- Includes developments since public 0.5.1: Store skills/MCP/AI Local, compatible API connections, toolbar model selection, unified conversations, Mix stage inspection and expanded settings.
- 73 tests, production build and Windows unpacked/portable launch checks passed.

## 0.5.1 — First public preview

- Refined chat spacing, expanding composer, integrated project/attachment tools, and expandable reports.
- Balanced light/dark colors; English default and Arabic support.
- Persistent profile, setup, preferences, and themed startup splash.
- Windows discovery, supported provider execution, and custom local connectors.
- 300 specialist roles with fixed Manager planning, dependencies, integration, and review.
- Project context, generated-file reports, conflict checks, and backups on Apply.
- Text/PDF/DOCX extraction, provider-dependent images, sampled video frames, and optional local audio transcription.

The preview is unsigned. AI providers or local model services are required. See the guide and FAQ for feature boundaries.
